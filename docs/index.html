the_workflow

Stop at the command that fits.

  1. model — Define your architecture in human-friendly YAML.
  2. validate — Check every relationship against ArchiMate 3.2 derivability rules.
  3. generate — Export .archimate Open Exchange XML for Archi.
  4. parse — Read existing .archimate files back into YAML.
  5. diff — Diff two models; see what was added, removed, or changed.

cli

Four commands.

$ archr validate --input model.yamlcheck model against derivability rules
$ archr generate --input model.yaml --output model.archimateexport Open Exchange XML
$ archr parse --input model.archimate --output model.yamlconvert XML back to YAML
$ archr diff --old existing.archimate --new updated.yamlsee what changed
