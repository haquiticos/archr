the_workflow

Define in YAML. Then pick the command.

  1. validate — Check every relationship against ArchiMate 3.2 derivability rules.
    archr validate --input model.yaml
  2. generate — Export .archimate Open Exchange XML for Archi.
    archr generate --input model.yaml --output model.archimate
  3. parse — Read existing .archimate files back into YAML.
    archr parse --input model.archimate --output model.yaml
  4. diff — Diff two models; see what was added, removed, or changed.
    archr diff --old existing.archimate --new updated.yaml

install

Rust 1.74+. One line.

# Cargo
$ cargo install archr-core

install script (macOS & Linux)

curl -fsSL https://raw.githubusercontent.com/haquiticos/archr/main/install/install.sh | bash

install script (Windows)

powershell -c "irm https://raw.githubusercontent.com/haquiticos/archr/main/install/install.ps1 | iex"

build from source

git clone https://github.com/haquiticos/archr && cd archr && cargo build --release

verify

archr --version # archr 1.0.0
